## 附录 B —— 复跑用的静态扫描脚本

```bash
python - <<'PY'
import re, pathlib
cats = ["启动","配置","窗口","OCR","发送","解析","异步","暂停","判定","决策","执行","报告","退出"]
for c in cats:
    total = 0
    for p in pathlib.Path('src/guild_auto').rglob('*.py'):
        text = p.read_text(encoding='utf-8')
        for m in re.finditer(r'logger\.log_\w+\(', text):
            if c in text[m.start():m.start()+400]:
                total += 1
    print(c, total)
PY
```
