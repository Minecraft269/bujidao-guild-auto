## 附录 B —— 复跑用的静态扫描脚本

**11 类日志关键词：**

```bash
python - <<'PY'
import re, pathlib
cats = ["启动","配置","窗口","OCR","发送","解析","异步","暂停","判定","决策","执行","报告","退出"]
for c in cats:
    total = 0
    for p in pathlib.Path('src/guild_auto').rglob('*.py'):
        text = p.read_text(encoding='utf-8')
        for m in re.finditer(r'logger\.log_\w+\(', text):
            if c in text[m.start():m.start()+400]:
                total += 1
    print(c, total)
PY
```

**`except: pass`（AST 口径）：**

```python
import ast, pathlib

hits = []
for p in pathlib.Path("src/guild_auto").rglob("*.py"):
    tree = ast.parse(p.read_text(encoding="utf-8"))
    for node in ast.walk(tree):
        if isinstance(node, ast.ExceptHandler):
            body = [n for n in node.body if not isinstance(getattr(n, "value", None), ast.Constant)]
            if len(body) == 1 and isinstance(body[0], ast.Pass):
                hits.append(f"{p}:{node.lineno}")
print("except:pass =", len(hits))  # 期望 0
```
