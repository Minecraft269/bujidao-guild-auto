> 本清单逐项提取自现有脚本源码(演示公会演示管理员.zip 解包),重构代码必须完整继承以下规则,不得丢失或更改。
> 源码位置参考:解包目录 文件1/B2/*/run_*.py(4 个判定脚本)、文件1/A1/parse_guild.py(解析)、文件1/C3/*(执行与公告)。

## 1. 等级划分与阈值矩阵

| 等级 | 源码文件 | 判定条件(周贡献 exp) | 操作 | 源码行号 |
|---|---|---|---|---|
| 高活跃 | run_auto.py | `exp <= 30000` | `demote` ×1 | run_auto.py:80 |
| 中等活跃 | run_mid.py | `exp >= 30000` | `promote` ×1 | run_mid.py:81-82 |
| 中等活跃 | run_mid.py | `exp < 5000` | `demote` ×1 | run_mid.py:83-84 |
| 低活跃 | run_low.py | `exp >= 30000` | `promote` ×2 | run_low.py:79-80 |
| 低活跃 | run_low.py | `exp >= 10000` | `promote` ×1 | run_low.py:81-82 |
| 低活跃 | run_low.py | `exp < 3500` | `demote` ×1 | run_low.py:83-84 |
| 入门成员 | run_entry.py | `exp >= 30000` | `promote` ×3 | run_entry.py:79-80 |
| 入门成员 | run_entry.py | `exp >= 10000` | `promote` ×2 | run_entry.py:81-82 |
| 入门成员 | run_entry.py | `exp >= 3500` | `promote` ×1 | run_entry.py:83-84 |
| 入门成员 | run_entry.py | `exp < 3500` | `kick` ×1 | run_entry.py:85-86 |

**边界语义(必须原样保留)**:
- 高活跃降职含边界(`<= 30000`),中等活跃升职含边界(`>= 30000`)——两者在 30000 处同值反向(原脚本如此,继承);
- 中等活跃降职为严格小于(`< 5000`),不含边界;
- 低活跃/入门成员的各分支均为含边界(`>=`),入门成员踢出为严格小于(`< 3500`);
- 判定顺序:先查升职分支,再查降职/踢出分支(if / elif 链,原脚本顺序)。

**等级链(升职 N 次对应的新等级)**:入门成员 → 低活跃 → 中等活跃 → 高活跃
- promote×1:入门→低 / 低→中 / 中→高
- promote×2:入门→中 / 低→高
- promote×3:入门→高

## 2. 命令格式(原脚本发送到游戏聊天)

| 用途 | 命令 |

| 查询成员 | `/guild member <玩家ID>` |

## 3. 通知文案(原脚本对每个查询成功成员发送)

| 操作 | 文案 |
|---|---|
| 无操作 | `{pid} 这周贡献为:{weekly} 执行操作:无 非常感谢你对公会做出的贡献 公会群:{GUILD_QQ}` |
| 升职 | `{pid} 这周贡献为:{weekly} 执行操作:升职({n}次) 非常感谢你对公会做出的贡献 公会群:{GUILD_QQ}` |
| 降职 | `{pid} 这周贡献为:{weekly} 执行操作:降职 若有异议请去群里找执行此操作的管理员 公会群:{GUILD_QQ}` |
| 踢出 | `{pid} 这周贡献为:{weekly} 执行操作:踢出 未完成这周最低标准 若有异议请去群里寻找执行管理员 公会群:{GUILD_QQ}` |

- `{n}` 为升职次数(promote 重复次数,原脚本 generate_notification 用 len(actions));
- 原脚本 GUILD_QQ 硬编码 `YOUR_QQ_GROUP`(run_auto.py:17 等 4 处)——重构后配置化,默认值沿用。

## 4. 周贡献计算口径(继承,含缺陷语义)

- 来源:游戏内 `/guild member <ID>` 面板的"公会经验周贡献"段;
- 计算:该段内**所有** `数值 公会经验` 行求和(含"今天"行),数值带千分位逗号(如 `1,322`)须去除后累加(get_weekly_exp,run_auto.py:68-75);
- 面板结构:"今天" + 近 7 天日期行,共 8 行(脚本的使用.md 示例)——求和口径原样保留。
