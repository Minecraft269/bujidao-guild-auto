## 逐点核验

### 1. `domain/reporter.py` `_render_roster` 标题与对账 verdict 按来源分派 —— 通过

`src/guild_auto/domain/reporter.py:708-719` 标题后缀四分支：

- `has_total and diff == 0` 且 `source_key in ("guild_list_panel", "guild_detail_tooltip")` → `无遗漏`
- 同上但来源为其它（含 `ui_paging_accumulated`）→ `未证明无遗漏`
- `has_total` 但 `diff != 0` → `差值 {diff},见对账`
- 无总数 → `无法对账`

`src/guild_auto/domain/reporter.py:756-766` 对账 verdict 同样三分派：`diff != 0` → `❌ 报告缺陷`；
可信来源 → `✅ 无遗漏`；`ui_paging_accumulated` → `⚠ 仅逐页累计...`；其余（含 `""`/`unknown`）
→ `⚠ 来源未知,差值为 0 不构成证明`。标题与正文同源，不再出现「标题宣称无遗漏、正文降级」的矛盾。

测试证据：`tests/test_report_analysis_branches.py` `TestMemberTotalSourceText`
覆盖 tooltip 标题「无遗漏」、paging 标题「未证明无遗漏」、缺总数「无法对账」、
paging 且 diff≠0 仍报「❌ 报告缺陷」、未知来源写「未知来源」；另 `test_ui_mode.py` 有
main→counts→report 的端到端来源标注断言（`逐页翻页累计`）。
